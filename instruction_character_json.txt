================================================================================
 ИНСТРУКЦИЯ ПО ЗАПОЛНЕНИЮ КАРТОЧКИ ПЕРСОНАЖА В ФОРМАТЕ JSON (D&D 5e)
================================================================================

Каждый персонаж сохраняется в отдельный файл с расширением .json в папку characters/
(например: characters/thorgrim.json или characters/char_1.json).

Файл можно открыть и редактировать в любом обычном Блокноте (Notepad), VS Code, 
Notepad++ или Sublime Text.

--------------------------------------------------------------------------------
1. ВАЖНЫЕ ПРАВИЛА ФОРМАТА JSON (ЧТОБЫ НЕ БЫЛО ОШИБОК)
--------------------------------------------------------------------------------
1. Кавычки: Все названия полей и текстовые значения должны быть строго в двойных 
   прямых кавычках: "поле": "значение". Одинарные кавычки ' ' использовать нельзя!
2. Запятые: Запятая ставится после каждого поля. 
   ВНИМАНИЕ: После самого последнего поля перед закрывающей скобкой } или ] 
   запятая НЕ ставится!
3. HTML-теги для красоты: Внутри описаний атак, умений и текста можно использовать:
   - <b>Жирный текст</b> — для названий способностей, кубиков и урона.
   - <i>Курсив</i> — для типов урона и примечаний.
4. Кодировка: Сохраняйте файл в кодировке UTF-8.


--------------------------------------------------------------------------------
2. ОПИСАНИЕ ВСЕХ ПОЛЕЙ КАРТОЧКИ
--------------------------------------------------------------------------------

• "id"             - Уникальный идентификатор персонажа на английском (без пробелов).
                     Пример: "char_thorgrim", "char_1", "rogue_finn"

• "name"           - Имя персонажа. 
                     Пример: "ТОРГРИМ", "ФИНН".
                     Если оставить пустым "", на карточке будет строчка под карандаш/ручку.

• "race"           - Раса персонажа.
                     Пример: "Дворф", "Полурослик", "Человек", "Лесной эльф"

• "class"          - Класс персонажа.
                     Пример: "Воин", "Плут", "Жрица Жизни", "Следопыт", "Маг"

• "meta"           - Предыстория и мировоззрение.
                     Пример: "Солдат | Законно-добрый", "Преступник | Хаотично-добрый"

• "level"          - Уровень персонажа (строкой).
                     Пример: "1", "3", "5"

• "maxBudgetPoints" - Сумма очков для распределения 6 характеристик (обычно "75").
                     Пример: "75"

• "ac"             - Класс Доспеха / Защита (КД).
                     Пример: "18", "14", "16"

• "acSub"          - Откуда берётся броня (пояснение под КД).
                     Пример: "Кольчуга + Щит", "Кожа (11) + Ловк (+3)"

• "hpMax"          - Максимальный запас здоровья (Хиты / HP).
                     Пример: "13", "10", "9"

• "hpCur"          - Текущее здоровье (обычно оставляют "", чтобы писать карандашом).

• "hpBonus"        - Временное здоровье / щит (обычно оставляют "").

• "speed"          - Скорость передвижения в футах.
                     Пример: "30 фт", "25 фт", "35 фт"

• "speedSub"       - Скорость в метрах.
                     Пример: "9 метров", "7.5 метров", "10.5 метров"

• "init"           - Модификатор Инициативы.
                     Пример: "+1", "+3", "+0"

• "initSub"        - Пояснение броска инициативы.
                     Пример: "d20 + 1", "d20 + 3"

• "extraTitle"     - Название 5-й ячейки уникального классового ресурса.
                     Пример: "Вдохновение", "Ячейки 1 круга", "Пасс. Внимание"

• "extraVal"       - Значение ресурса.
                     Пример: "□", "□ □", "13"

• "extraSub"       - Подпись ресурса.
                     Пример: "Переброс d20", "2 слота / день", "Чутьё"

• "abilities"      - 6 базовых характеристик (СИЛА, ЛОВКОСТЬ, ТЕЛОСЛОЖ., ИНТЕЛЛЕКТ, МУДРОСТЬ, ХАРИЗМА).
                     Для каждого параметра указывается "score" (число от 1 до 20) 
                     и "mod" (модификатор: +3, +1, -1 и т.д.).
                     Таблица модификаторов:
                     - Счёт 8-9   -> Мод "-1"
                     - Счёт 10-11 -> Мод "+0"
                     - Счёт 12-13 -> Мод "+1"
                     - Счёт 14-15 -> Мод "+2"
                     - Счёт 16-17 -> Мод "+3"
                     - Счёт 18-19 -> Мод "+4"
                     - Счёт 20    -> Мод "+5"

• "attacks"        - Список оружия и заклинаний атаки. 
                     Каждый элемент содержит:
                     - "name": Название оружия
                     - "hit":  Бросок на попадание (например: "d20 + 5", "Спас ЛОВ 13")
                     - "dmg":  Урон и тип (например: "1d8 + 3 рубящий", "1d4 + 3 колющий")

• "deathSuccess"   - Успехи спасбросков от смерти (0, 1, 2 или 3). По умолчанию 0.

• "deathFail"      - Провалы спасбросков от смерти (0, 1, 2 или 3). По умолчанию 0.

• "inventory"      - Список переносимого снаряжения, золота, доспехов и расходников.
                     Пример: "Кольчуга, щит, длинный меч, 2 топора, ранец, фляга, 10 gp."

• "features"       - Список главных способностей, фишек расы и заклинаний персонажа.
                     Каждый пункт — отдельная строчка в кавычках.

• "description"    - Подробное описание, предыстория, внешность и цели персонажа 
                     (печатается на оборотной стороне карточки).

================================================================================
5. КАК ПОДКЛЮЧИТЬ ЗАПОЛНЕННЫЙ ФАЙЛ В ИГРУ
================================================================================
1. Сохраните готовый файл с расширением .json (например: wizard.json).
2. Положите его в папку characters/ вашего проекта.
3. Запустите игру через start.bat (или обновите страницу в браузере).
4. Новый персонаж автоматически появится среди вкладок со всеми своими статами!
